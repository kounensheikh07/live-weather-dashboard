# Live Weather Dashboard

## Project
Asynchronous JavaScript & RESTful APIs

## Features
- Fetch API with async/await
- City search
- Live weather data
- Error handling for failed requests
- JSON parsing and dynamic DOM rendering
- Temperature, humidity, wind speed, feels-like temperature and cloud cover
- Responsive design

## API
Open-Meteo Geocoding API:
https://geocoding-api.open-meteo.com/v1/search

Open-Meteo Forecast API:
https://api.open-meteo.com/v1/forecast

## How to run
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to a GitHub repository.
Then go to:
Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save
